# Featherline Flats

## Description

A dust-dry plain claimed for the Blood Bowl's second act, run on the same Roll20 map as
[Cimarron Flats](cimarron-flats.md) but *not* the same place in-fiction — see DM Only. Earth-like,
with a dust-bowl, Utah-ish feel, except every animal on it is Aether-touched: herds of rhino-sized
[Aether Hornbacks](../races/aether-hornbacks.md) graze the open ground, and the fields themselves
seem to test anyone crossing them. A windmill stands over the hex's Pylon.

## Notable Locations

- **The windmill and Pylon** — an Agent-branded Pylon stands at the windmill's foot, same device
  as the one in Briarwood's fountain court.
- **The shed** — a small, out-of-place structure standing alone in a field, covered in anti-Agent
  graffiti. Near it, [Agent](../npcs/agent.md)'s feed goes quiet. See
  [Session 9](../../sessions/09-a-glitch-in-the-signal.md) for what the party found there.

## What the Party Knows

Crossed it on the way north toward [Meridian Peak](../factions/meridian-peak.md) in
[Session 9](../../sessions/09-a-glitch-in-the-signal.md); won the Pylon from the
[Cult of the Swan](../factions/cult-of-the-swan.md) in a pageant rather than a fight, then found the
shed.

## DM Only

**Not Cimarron Flats.** [A Glitch](../../encounters/a-glitch.md) deliberately reuses the Cimarron
Flats Roll20 map for a distinct hex so as not to conflict with the actual
[Cimarron Flats](cimarron-flats.md) (held by the [Black Sunday Kin](../factions/black-sunday-kin.md)).
The table called this hex "Cimarron Flats" at the table because they recognized the map — that's a
real naming collision worth flagging, not a contradiction to quietly resolve. Keep this file
separate from the real Cimarron Flats; rename either file if the collision keeps causing confusion
at the table.

**Status as of Session 9:** the party holds the Pylon here (Ending: The Cult Yields, per
[A Glitch](../../encounters/a-glitch.md)) and the Cult of the Swan asked for refuge rather than be
retired. `controlled_by` left `null` pending a decision on whether Briarwood itself should be
represented as a faction file for Pylon-holding purposes.

**The shed is the open thread.** Agent's feed goes silent near it, and graffiti points "west" to
more free zones. What's actually in/around the shed is deliberately unresolved — see Session 9's
DM Only for the full list of open questions.
