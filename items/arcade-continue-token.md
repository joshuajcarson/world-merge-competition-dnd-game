# Arcade Continue Token

*Wondrous Item, Uncommon*

When you would be reduced to 0 hit points but not killed outright, you can
expend this token (no action required) to instead drop to 1 hit point
instead. The token is then spent. Insert coin to continue; there's no second
play.

## Flavor

A single arcade token, Aladdin's Castle stamped into one face and worn smooth
on the other from a thousand kids' thumbs — except this one is warm, and
holding it up to any screen for a second makes the screen flicker with a
health bar that isn't the game's.

## DM Notes

- **Why it's here:** loose in the token hopper or a coin tray at
  [Briarwood Mall](../world/places/briarwood-mall.md)'s Aladdin's Castle
  arcade — an easy, thematic scattered find, same "opening equipment list"
  logic as the mall's other Common items, just a step rarer.
- **Hooks:** none required — this is a pure safety-net item, best discovered
  before the party needs it rather than after.
- **Balance note:** doesn't prevent instant death from damage that kills
  outright (massive overkill still kills as normal) — it only converts an
  ordinary "reduced to 0" into "reduced to 1," which keeps it inside the
  Uncommon "noticeable but not defining" combat-impact band rather than
  reading as a true resurrection effect.
