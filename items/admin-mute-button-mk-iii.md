# ADMIN Mute Button, Mk. III

*Wondrous Item, Uncommon*

As an action, you press this button and choose a point within 60 feet. For 1 minute, a 20-foot-radius sphere
centered on that point is completely silent. Sound can't be created within or pass through the sphere.
A creature fully inside the sphere is immune to thunder damage and can't cast spells that
require a verbal component. The sphere doesn't move, and it ends early if you use a bonus
action to press the button again. The button is dead after it has been used once.

## Flavor

A red square the size of a coaster, with a recessed button, a stamped serial number, and a printed
warranty that voids on first use. It was pulled from the Administration's own production-room stock,
and it clicks like a very expensive remote. While the area is silent, the only sound anyone can
hear is a tiny, distant, very aggrieved "*rude*," which no one can place.

## DM Notes

- **Why it's here:** an obvious pregame reward from [Agent](../world/npcs/agent.md), planted by
  Agent itself for the audience, which is exactly why it's funny: the one thing Agent can't
  narrate through is the sphere. It is a good tool against casters and against anything that
  works through sound.
- **Hooks:** Agent notices. Expect a mild, amused complaint and maybe a ratings ding for the
  party, "since the audience couldn't hear it."
- **Balance note:** equivalent to the 2nd-level *Silence* spell with no concentration. Note
  that it will switch off verbal spellcasting inside the sphere for **everyone**,
  including your own party's casters.
